# Smart Document Hub

A web-based document conversion tool designed to simplify document text extraction and conversion.

## Features

* Upload PDF documents
* Extract text from PDF files
* Display extracted document content
* Convert and download document content
* Simple and user-friendly interface
* Responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript
* PDF.js
* DOCX generation

## How to Use

1. Open the Smart Document Hub application.
2. Upload a PDF document.
3. Click the conversion button.
4. View the extracted text.
5. Download the converted document.

## Project Purpose

This project was developed as a practical document conversion solution and demonstrates skills in web development, document processing, JavaScript, and user interface design.
